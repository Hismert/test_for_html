Реакции 1 порядка

Пар (Пиро + Гидро).Таяние (Крио + Пиро).Обострение (Стимуляция + Электро).Разрастание (Стимуляция + Дендро).

Реакции 2 порядка

Перегрузку (Пиро + Электро); Заряжен (Гидро + Электро); Сверхпроводник (Крио + Электро); Заморозку (Гидро + Крио); Разбит (Удар двуручным мечом по цели, находящейся в состоянии Заморозки). Бутонизация (Гидро + Дендро). Разрыв (Бутонизация + бездействие) Горение (Пиро + Дендро). Вегетация (Бутонизация + Электро). Цветение (Бутонизация + Пиро).

Реакции 3 порядка

Рассеивание (Анемо + Пиро/Крио/Гидро/Электро); Кристаллизацию (Гео + Пиро/Крио/Гидро/Электро). применяется
